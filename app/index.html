EngageSense · MSc/BSc project artefact · Client-side mode runs face detection, feature extraction and classification locally via MediaPipe Face Mesh + TensorFlow.js; no image is transmitted. Server-side mode is provided only to benchmark the conventional architecture (Objective 3). When trained models are absent, a transparent, literature-grounded heuristic detector is used so the system remains fully demonstrable.
